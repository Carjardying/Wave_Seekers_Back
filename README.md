# Wave Seekers 

Application Mobile dédiée à la recherche de spots de surf.

Type : collectif — 4 personnes   
Durée : 2 semaines.  Sprint 1 Front. Sprint 2 Back   
Période : 9eme mois de formation   

## Stack  

Android Studio, Kotlin
VSCode, Golang, Gin gonic
- Langages / Frameworks : Kotlin (sans framework), Golang (Gin Gonic). Pas d'ORM
- Base de données : SQLite  
- Outils / Services : VSCode - Android Studio — Postman

  ## Fonctionnalités et compétences

| Fonctionnalité                      | Compétence acquise                                                               |
| ----------------------------------- | -------------------------------------------------------------------------------- |
| **Création d'une API REST**         | Développement de routes, contrôleurs et logique de traitement                    |
| **Création d'une base de données**  | Utilisation de SQLite pour une approche plus transportable                       |
| **Gestion des requêtes HTTP**       | Mise en place de routes `GET`, `POST`, `DELETE` et `PUT`                         |
| **Filtrage des données**            | Affichage conditionnel (ex:  affichage des spots de surfs d'un pays uniquement)  |
| **Formatage des réponses API**      | Structuration des retours en JSON pour consommation Frontend                     |
